Aprendizaje comprobable

Flujo de métodos HTTP y SQL

GET

Leer y buscar

Solicita los registros mediante consultas SELECT parametrizadas sin alterar la base de datos.

GET /api/productos
POST

Crear

Valida el formulario, inserta el registro y responde con el nuevo identificador.

POST /api/productos
PUT

Reemplazar

Exige todos los campos y reemplaza el estado completo del recurso seleccionado.

PUT /api/productos/:id
PATCH

Actualizar una parte

Modifica solamente los campos enviados, por ejemplo el stock o el estado.

PATCH /api/productos/:id
DELETE

Eliminar

Realiza una baja lógica para conservar la trazabilidad de ventas e inventario.

DELETE /api/productos/:id
QUERY

Consulta educativa

Ejecuta los mismos filtros del buscador, pero exige el verbo personalizado de la guía.

QUERY /api/productos/consulta
