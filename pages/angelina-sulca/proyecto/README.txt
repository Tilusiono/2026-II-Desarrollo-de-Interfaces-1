PROYECTO: SchoolSupply

DESCRIPCIÓN:
Tienda virtual de útiles escolares con POO en JavaScript.

ESTRUCTURA:
- index.html: Página principal con Bootstrap
- css/styles.css: Estilos personalizados
- js/main.js: Punto de entrada y demostración
- js/ui.js: Interfaz de usuario
- js/models/: Todas las clases
- js/data/: Instancias de prueba

CÓMO EJECUTAR:
1. Abrir index.html en un navegador
2. Abrir consola (F12) para ver la demostración

- CSS3 / Bootstrap 5
